# 회사 와이파이에서 맥북 조회만 하기

> 현재 이카운트 연결은 사용 중지했습니다. PC 설치가 필요하지 않습니다. 현재 업무는 [물류팀 전달 엑셀](LOGISTICS_QUANTITY_EXPORT.md)을 사용하며, 아래 내용은 이전 구현 참고입니다.

현재 회사 인터넷 공인 IP는 2026-11-10 확인 당시 이카운트에 이미 등록된 주소와 일치했습니다. 고정 IP 계약 여부는 확인되지 않았습니다.

## 실행

저장소에서 Node 22.13 이상으로 실행합니다.

```sh
node --experimental-strip-types scripts/ecount-local.mjs
```

브라우저에서 `http://127.0.0.1:3111/`에 접속합니다. 이 맥북에서만 열리며 사내 다른 기기에 노출하지 않습니다.

사용자가 회사코드·API 사용자 ID·기존 운영 인증키를 화면에 직접 입력한 뒤 「샌드부스터 재고 조회만 실행」을 누릅니다. 키를 채팅으로 보내거나 환경변수 파일에 적지 않습니다. 입력값은 조회 시작 시 화면에서 지워지고 서버에서는 파일·로그·응답에 저장하거나 출력하지 않습니다. 브라우저의 비밀번호 저장 제안도 승인하지 않는 것이 좋습니다.

## 범위

- ZONE 자동 조회 → 운영 로그인 → 창고 200 샌드부스터 조회.
- V코드 품목만 표시. 유기농 홍화씨 V00100110 제외.
- 수량을 임의로 반올림·변환하지 않습니다. 이카운트 등록 단위를 사용합니다.
- SCM·Neon·구글시트 접근, 재고 반영, 방송 원가·이익 변경, 전표 입력 기능이 없습니다.
- 기존 운영 SCM의 버튼은 여전히 Vercel에서 호출합니다. 이 로컬 조회 도구가 해당 버튼의 서버 경로를 자동 변경하지 않습니다.
- 신규 유료 서비스·고정 IP 상품·인증키 발급이 없습니다.

## 보호와 상태

외부 출처 요청을 거부하며 허용 경로는 조회 화면과 상태 확인 및 조회 요청뿐입니다. 서버 상태 `/status`에는 성공 여부·품목 개수·정제된 오류만 포함됩니다. 인증 값·세션·재고 원문은 포함하지 않습니다.

`work/ecount-local-state.json`에는 다음 호출 가능 시각과 인증 실패 횟수만 보관합니다. 인증키는 보관하지 않습니다. 일반 조회는 10분 제한, 인증 실패는 1시간 대기, 3회 실패 후 반복 호출 중단입니다. 실행 종료 후에도 실패 제한을 유지합니다. 이 파일을 지워 반복 호출하지 마세요.

네트워크가 변경되면 허용 IP 오류가 날 수 있습니다. 회사 와이파이 또는 같은 출발 공인 IP의 회선을 사용하세요. 맥북이 절전·종료되면 로컬 도구도 사용할 수 없습니다.

종료할 때 실행 중인 터미널에서 Ctrl+C를 누릅니다. 지속 자동 운영용 서버나 백그라운드 서비스로 설치하지 않았습니다.
