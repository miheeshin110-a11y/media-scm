# 물류팀 전달 수량 엑셀

## 현재 업무흐름

방송팀의 저장 방송 → 물류 SCM에서 방송 기간·방송 선택 → 물류팀 전달 엑셀 다운로드 → 물류팀이 기존 재고관리 파일에서 재고·입고·부족분 계산.

이카운트 연결과 PC 연결 메뉴는 사용하지 않습니다. 기존 연결·작업 이력은 삭제하지 않습니다. 구형 API의 조회/반영/새 PC 연결은 410으로 중지하고, PC 에이전트 인증 경로는 401로 중지해 옛 프로그램이 ERP 조회 없이 정지하도록 했습니다. 기존 인증키·로그인·Neon·구글시트 환경변수는 변경하지 않습니다. 물류팀 PC 프로그램 설치·실행은 필요 없습니다.

## 다운로드

- 물류 SCM 상단 「물류팀에 방송 준비수량 전달」.
- 날짜를 비우면 저장 방송 전체를 대상으로 합니다. 기간 또는 특정 방송을 선택할 수 있습니다.
- 기간을 지정하면 방송일 미입력 방송은 제외됩니다. 기간을 비우면 미확정 방송도 「확인 필요」에 포함됩니다.
- 「물류팀 전달 엑셀 다운로드」를 누르면 XLSX 한 파일이 만들어집니다.

| 시트 | 내용 |
| --- | --- |
| 방송별 수량 | 방송일·시간·채널·상품·메인/서브 판매구성·본품/사은품·V코드·품목명·단위·준비수량·예상출고수량·확인사항 및 산출근거·방송 ID/버전 |
| 품목별 합계 | V코드·본품/사은품 구분·단위별 선택 방송 합계 |
| 확인 필요 | 미확인 입력·구성표 미등록·일정 미확정·유기농 홍화씨 보류·취소 등 |
| 전달 안내 | 다운로드 시각·수량 기준·단위·미확인 및 파일 교체 방법 |

## 계산 기준

준비수량은 요청 세트수 × 확인된 단품 구성수량입니다. 예상출고수량은 각 메인/서브 구성의 전환율과 기존 수량 처리기준을 먼저 적용한 뒤 단품 구성수량을 곱합니다. 본품·사은품은 행을 나누며, 함께 전달된 사은품을 다시 가산하지 않습니다.

방송일에 유효한 구성수량 이력을 사용합니다. 빈 입력이나 미등록 구성을 0으로 만들지 않습니다. 유기농 홍화씨는 수량과 합계에서 제외하고 사유만 전달합니다. 단위가 다르면 임의 환산하거나 합치지 않습니다. 미확인 수량이 들어간 품목 합계는 빈칸입니다. 구성 자체를 알 수 없는 제외 항목은 합계에 들어가지 않으므로 확인 필요 시트도 함께 확인합니다.

엑셀에 원가·이익·PPL 금액이나 인증정보는 넣지 않습니다. 파일 생성은 클라이언트 읽기 전용 계산이며 DB·재고·방송결과·구글시트·물류 준비 상태를 저장하지 않습니다. 다운로드 후 방송이 바뀌면 방송 ID·버전을 기준으로 이전 파일을 교체하고 반복 누적하지 않습니다.

연동할 기존 물류팀 시트는 읽기만 확인했으며 자동 입력·수식 변경은 하지 않았습니다.
