# Windows 물류팀 PC와 운영 SCM 연결

> 현재 이카운트 연결은 사용 중지했습니다. PC 설치가 필요하지 않습니다. 현재 업무는 [물류팀 전달 엑셀](LOGISTICS_QUANTITY_EXPORT.md)을 사용하며, 아래 내용은 이전 구현 참고입니다.

## 구성

기존 SCM·Neon·구글시트를 유지합니다. 물류팀 PC의 공인 IP가 이미 이카운트 허용 주소와 일치한다고 사용자가 확인했습니다. 새 유료 서비스나 고정 IP 상품을 추가하지 않습니다. 기존 Vercel·Neon의 요청·저장 사용량은 발생합니다.

운영 SCM에서 조회 요청 → Windows 프로그램이 HTTPS로 요청 확인 → 회사 회선으로 이카운트 창고 200 조회 → 결과만 SCM 확인 화면으로 전달합니다. SCM 재고 반영은 기존 별도 확인 버튼으로만 수행합니다.

- PC 인바운드 포트나 공유기 포트포워딩을 열지 않습니다.
- 로컬 설정 화면은 `127.0.0.1:3112`에서만 열립니다.
- 회사코드·운영 API ID·기존 운영 인증키는 PC에서 이카운트로만 전송합니다. 새 이카운트 키를 발급하지 않습니다.
- 사용자 선택 시 Windows DPAPI CurrentUser로 PC 인증정보와 연결 토큰을 암호화합니다. 키를 평문 파일·로그·명령줄 인수에 쓰지 않습니다. SCM에는 이카운트 키를 보내지 않습니다.
- PC 연결코드(10분·1회)와 PC 인증 토큰(180일)은 이 프로그램의 조회 요청·결과 전달 전용입니다. 서버에는 해시만 저장하며 방송/finance API 접근 권한을 부여하지 않습니다. 관리자만 PC를 등록·해제합니다.
- 유기농 홍화씨 V00100110은 PC와 서버 양쪽에서 제외합니다.
- PC에서 별도 수동 조회 프로그램을 동시에 실행하지 않습니다.

## 설치 대상

Windows 10/11 **64비트 x64**, 업무시간 동안 켜진 PC. 최초 설정은 해당 Windows 사용자로 로그인한 상태에서 수행합니다. 다른 Windows 계정은 암호화한 설정을 읽을 수 없습니다.

설치 묶음에는 공식 Node.js Windows x64 실행 파일과 공개 체크섬 검증 기록을 포함합니다. 별도 유료 프로그램은 필요 없습니다. 실제 Windows 설치·자동 실행·DPAPI 동작은 대상 PC에서 확인해야 합니다. Mac에서 Windows 동작을 검증했다고 간주하지 않습니다.

## 담당자 실행 순서

1. 설치 ZIP을 물류팀 PC로 옮겨 **압축을 완전히 풉니다**. ZIP 안에서 바로 실행하지 않습니다.
2. `Install.cmd`를 더블클릭합니다. 프로그램을 `%LOCALAPPDATA%\MediaSCMBridge\app`에 복사하고 현재 사용자 로그인 시 자동 실행되도록 시작프로그램 바로가기를 만듭니다.
3. 물류팀 PC 브라우저에서 기존 SCM에 **관리자 계정**으로 로그인 → 물류 SCM → **물류팀 PC 연결 설정**.
4. PC 이름을 확인하고 **PC 연결코드 준비 → 연결코드 복사**. 코드를 채팅·메일로 보내지 않습니다.
5. 자동으로 열린 `http://127.0.0.1:3112/` 화면에 연결코드·회사코드·운영 API 사용자 ID·기존 운영 인증키를 직접 입력합니다.
6. 전용 Windows 계정에서 **이 Windows 계정으로 암호화해 보관하고 다음 로그인부터 자동 연결**을 선택하면 재부팅 후 재입력을 줄일 수 있습니다. 선택하지 않으면 프로그램을 다시 켤 때 재입력이 필요합니다.
7. **이 PC 연결**을 누릅니다. 입력칸은 지워지고, 잠시 후 「SCM 연결됨」을 확인합니다. 이 단계는 이카운트 재고를 자동 조회하거나 반영하지 않습니다.
8. 운영 SCM에서 **이카운트 재고 불러오기**를 누릅니다. PC 확인 주기 최대 20초 + API 응답 시간 후 결과가 표시됩니다.
9. 최초 확인 때는 **재고 반영 버튼을 누르지 않습니다**. 샌드부스터·V코드·단위를 대조한 뒤 반영 여부를 결정합니다.

사용자는 관리자 계정 로그인과 인증정보 입력을 직접 수행합니다. 인증키·PC 연결코드를 채팅으로 보내지 않습니다.

## 매일 사용

- Windows 로그인 후 프로그램이 자동 실행됩니다. PC가 단순히 전원만 켜진 상태에서 로그인하지 않으면 자동 실행되지 않습니다.
- 처음 입력 시 암호화 저장을 선택했어야 자동 연결됩니다.
- 로컬 설정 창을 닫아도 프로그램이 실행 중이면 요청을 처리합니다.
- 절전·종료·인터넷 끊김 시 새 조회 불가. SCM에는 PC 응답 없음 안내를 표시하고 기존 재고를 유지합니다.
- SCM은 최근 10분 조회 결과를 재사용할 수 있으며 조회 기준일·시각을 표시합니다.
- 물류 PC가 사무실 밖으로 이동하거나 회선 공인 IP가 바뀌면 허용 IP 오류가 날 수 있습니다.
- 인증 실패 시 자동 재호출하지 않습니다. 1시간 대기·누적 3회 실패 차단이 있으므로 반복 클릭하지 않습니다.

## 해제

SCM 관리자 화면에서 해당 PC의 **PC 연결 해제**를 누르면 토큰을 폐기합니다. PC의 로컬 화면에서 **이 PC에 저장한 연결 삭제**로 암호화 보관 파일을 삭제할 수 있습니다. `Uninstall.cmd`는 시작프로그램 바로가기를 제거합니다. 실행 중인 프로그램과 설치 파일은 사용자가 종료·정리합니다.

## 검증 경계

임시 PostgreSQL 테스트: 연결코드 만료·단일 사용, 토큰 원문 미저장, 연결 해제, PC 오프라인, 요청 중복 방지, 단일 PC 작업 인수, 창고 제한, 결과 만료·재전송 차단, 인증 오류 정제·대기, 조회만으로 finance 미변경, 명시적 재고 반영 후에도 방송 원가·이익·PPL·기준정보 유지.

Mac의 회사 회선에서 이카운트 창고 200의 실제 조회는 이미 성공했습니다. **물류팀 Windows PC 설치·운영 SCM과의 왕복 조회 성공은 현장 확인 전까지 미검증입니다.**
